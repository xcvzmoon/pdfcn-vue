# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers building PDF documents in Vue and Nuxt.

## Product Purpose

Help developers install, understand, customize, and render pdfcn-vue components and document templates.

## Capabilities and Constraints

Nuxt is the website framework. Forme is the PDF renderer. Preserve the migrated Vue documentation, component props, block samples, registry distribution, and live PDF examples. Include a working theme builder, responsive layouts, and motion-v animations.

## Brand Commitments

The user requested modern technical brutalism, Swiss editorial typography, and terminal and industrial UI influences. The default website theme is dark with restrained neutral surfaces and borders. Code examples use Shiki highlighting. Write direct, specific developer documentation. Credit the original pdfcn project without claiming its React or Takumi capabilities for this port.

## Evidence on Hand

packages/registry contains Vue components, blocks, sample data, and nine theme presets. apps/website/app/components/content and apps/website/app/data contain the migrated documentation. https://www.pdfcn.dev/ is the original project's reference website. No customer counts or performance claims have been supplied.
